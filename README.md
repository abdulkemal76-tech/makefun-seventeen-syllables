One haiku about debugging, in the 5-7-5 shape. Entry for the make.fun
bounty "Seventeen Syllables of Debugging".

> The log says all green
> users scream, but nothing works
> the lie was all mine

## Run

```sh
python3 -P -s main.py
```

It writes the haiku to `/output/entry.txt` (plain text, 75 characters).
